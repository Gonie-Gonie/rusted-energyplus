# CLK-06 완료 반영과 임시 실행파일 정리 기록

`manifest.json`은 실제 완료 반영·정리 계획·삭제 실행·검토·레지스트리 및 소스의
36개 기록을 원본 바이트로 보관한다. `objects/*.part`는 JSON·문서·소스·실제 삭제 로그이며,
실행파일이나 Native 수치 trace는 포함하지 않는다. 모든 복사본의 크기와 SHA-256을 확인했다.

CLK-06 완료 반영, 정리 계획, 삭제 실행은 모두 실제 종료 코드 0이다. 완료 반영은
다른 63개 카드의 원래 JSON 바이트와 의미를 유지하면서 CLK-06의 네 gate만 변경했다.
실제 완료 당시 plan·card의 전후 바이트와 완료 증거를 함께 보존한다.

삭제 명령은 검증된 `clk06_reference_helper.exe` 디버그 원본 하나만 제거했다.
제거 용량은 1,297,365,278바이트다. 기존 21개 보호 파일과 CLK-06 실행용 파생 파일을
포함한 22개 파일의 바이트가 전후 일치했고, 삭제 대상의 실제 부재도 확인했다.
실제 v5 → admitted v6 → retired v6 계보를 보관한다.

150,595,264바이트의 검증된 실행용 파생 파일을 유지한다. 버린 디버그 바이트를 해시나
map으로 복구할 수 있다고 주장하지 않는다. 빌드·수치 비교를 다시 실행하거나,
기존 실패 기록을 성공으로 바꾸지 않았다. 이전 source review는 당시 범위의 이력으로만 남긴다.
