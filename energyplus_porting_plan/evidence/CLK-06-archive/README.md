# CLK-06 검증 증거 보관

`archive.json`은 실제 보고서 74개, 선택 소스 716개, 실패 실행 9건의 receipt와 로그를
연결한다. `objects/*.part`는 원본 바이트를 보존한 객체이며, manifest에 압축 방식과
복원 후 SHA-256·크기를 기록했다. 각 저장 객체는 4MB 이하이고 전체 보관본은 약 10.6MB다.

실제 보관 명령과 별도 byte 검증 명령은 모두 종료 0이다. 408개 고유 원본 객체가
정확히 복원되었으며, 이 디렉터리의 manifest와 저장 객체도 실제 보관본과 바이트가 같다.
검증기는 수치 피연산자를 다시 계산하지 않는다.

단위 비교 1,562,575개와 생산 비교 4,013,777개에서 불일치가 0개였고, 별도 결과 QA가
실제 보고서와 실행 기록을 인증했다. 완료 범위와 불가용·unpaired 항목은
`../CLK-06.json` 및 `../../cards/CLK-06.md`를 따른다. 과거 gap과 실패를 성공으로 바꾸지 않았다.

Native 실행파일과 348MB 원시 Native trace는 복사하지 않았다. 원시 trace는 실제 DataQA가
확인한 로컬 identity로 연결하며, 전체 reference wrapper 보고서는 바이트 보관에 포함한다.
