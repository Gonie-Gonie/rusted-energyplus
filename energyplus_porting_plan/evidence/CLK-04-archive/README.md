# CLK-04 증거 원문 보존

`archive.json`은 실제 검증 기록 64개와 소스 85개를 원문 바이트로 보존합니다. 중복 제거 후 146개 객체의 저장 크기는 3,397,230바이트입니다. 각 행의 `binding`은 당시 파일의 경로와 SHA-256이며, `storage`는 이 저장소 안에서 복원할 객체와 조각 순서를 지정합니다.

각 `parts`를 `index` 순서로 연결하고 `encoding`에 따라 gzip을 풀거나 그대로 읽으면 원문을 복원할 수 있습니다. 조각·연결한 저장 바이트·복원한 원문의 크기와 SHA-256을 각각 검사합니다. 실제 복원 검사에서 146개 객체 모두 원문과 일치했습니다. JSON 재직렬화나 수치 결과 변경은 수행하지 않았습니다.

`supplement/archive.json`은 실제 완료 문서 작성 결과, 작성 소스, 완료 당시의 계획·카드·증거 파일 및 작성 전 상대경로 오류 기록을 별도로 보존합니다. 12개 객체의 실제 복원 검사도 통과했습니다. 부모 archive는 수정하지 않았습니다.

원본 native 종료 0, 당시 wrapper 종료 1, metadata recovery 종료 0의 이력과 과거 단위·생산·Clippy 실패를 유지합니다. 당시 경로는 이력 식별자이며, 복원한 소스가 새 위치에서 바로 실행된다는 의미는 아닙니다. 큰 native 결과·CLI trace·실행 파일은 로컬 검증 캐시에 남아 있고 이 archive에 복제하지 않았습니다.

완료 범위와 한계는 [카드](../../cards/CLK-04.md)와 [완료 증거](../CLK-04.json)를 참조하십시오. 일사·하늘 및 후속 카드의 물리식은 이번 완료 범위에 포함하지 않습니다.
