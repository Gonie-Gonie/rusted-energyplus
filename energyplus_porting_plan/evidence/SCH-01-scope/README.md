# SCH-01 범위 문서 보완 기록

선정 Constant/Compact/TypeLimits의 원본 행 범위, 실제 입력 순서·초기화·부분 상태와 비교 경계를 보완했다. 실제 작성 명령은 exit 0이며 코드 바이트는 실행 전후 동일하다. 다른 63개 카드는 보존했고 SCH-01의 네 완료 항목은 모두 미확인이다. 이 기록은 수치 시험이나 PASS를 주장하지 않는다.

`manifest.json`은 실제 명령·전체 결과·작성 소스·승인된 입력·문서 변경 전후·전체 diff·코드 snapshot의 저장 위치와 SHA-256을 연결한다. `.part`는 원래 바이트의 identity 또는 gzip 저장본이며 각 객체를 복원하여 원래 해시와 일치함을 확인했다. 중복 객체는 동일 해시 파일 하나로 보관한다.
