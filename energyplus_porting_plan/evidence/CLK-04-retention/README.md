# CLK-04 검증 도구 정리 기록

CLK-04 완료 후 새 디버그 원본 `clk04_reference_helper.exe` 하나를 실제 삭제해 1,297,205,477바이트를 확보했습니다. PowerShell의 단일 `LiteralPath` 삭제는 종료 0으로 끝났고, 실제 파일 부재를 확인했습니다. 검증된 파생 실행 파일, 기존 도구·라이브러리, 실패 재현용 원본 등 보존 대상 20개는 삭제 전후 일치했습니다.

`archive.json`은 검토 소스·실제 사전 검사·삭제 명령과 결과·보존 레지스트리 v4의 원문 36개를 중복 제거한 24개 gzip 객체로 보존합니다. 조각을 순서대로 연결하고 압축을 푼 뒤 각 크기와 SHA-256을 검사하면 원문을 복원합니다. 실제 복원 검사에서 24개 모두 원문과 일치했습니다.

이번 정리는 계산 재실행이나 완료 gate 변경을 수행하지 않았습니다. 삭제된 디버그 바이트의 사본은 만들지 않았으며, 해시나 PE map으로 그 바이트를 복구할 수 있다는 주장을 하지 않습니다. 당시 native 0 / wrapper 1 / metadata recovery 0의 이력도 유지했습니다.

계산 검증 자료는 [완료 증거](../CLK-04.json)와 [원문 보존](../CLK-04-archive/README.md)을 참조하십시오.
