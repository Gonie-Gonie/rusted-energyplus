# CLK-05 임시 실행 파일 정리와 문서 수정 기록

`manifest.json`은 원본 바이트를 그대로 보관한 26개 기록을 연결한다. `objects/*.part`는
실행 파일이 아닌 JSON·소스·문서·실제 삭제 로그의 보관 바이트다. Git에서 binary로
취급해 원본 줄바꿈과 해시를 보존한다.

실제 삭제 명령은 검증된 CLK-05 디버그 실행 파일 하나만 제거했고 종료 코드 0이었다.
제거 용량은 1,296,986,812바이트이며, 기존 파일과 CLK-05 실행용 파생 파일을 포함한
21개 보호 파일의 바이트를 전후 검증했다. 실제 v4 → admitted v5 → retired v5 계보를
함께 보관한다. 버린 디버그 바이트를 해시로 복구할 수 있다고 주장하지 않는다.

첫 정리 계획은 기존 빌드의 요약 JSON을 전체 보고서로 잘못 가정해 종료 코드 1이었다.
그 실행과 당시 소스 검토를 보존하고 실제 세 키의 요약·보고서·실행 파일 참조를 검증하는
새 소스 검토 및 계획을 통과시켰다. 빌드나 과학 비교를 다시 실행하지 않았다.

완료 카드의 추가 한글 설명은 PowerShell stdin 인코딩으로 일부 문자가 깨졌다.
실제 완료·정리 당시 문서와 증거는 보존하고, 별도 종료 코드 0의 문서 수정으로 설명만
복구했다. `documentation-amendment` 기록은 과거 완료 카드와 현재 카드의 해시를 연결하며
계획·완료 증거·게이트·수치 결과를 변경하지 않는다.
