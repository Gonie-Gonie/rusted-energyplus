# 단일 카드 작업 지시문 틀

대상 카드: `<ID>`

1. cards/<ID>.md와 선행 카드의 출력 계약만 먼저 읽는다.
2. 지정 EnergyPlus 커밋의 해당 파일·함수·분기를 읽고, 실제 코드 start/end 및 필요한 helper 목록을 기록한다.
   원본 .hh에서 실제 사용 필드만 가져온다. 범위 밖의 프로젝트 전역 재탐색은 필요한 이유를 기록한 뒤 수행한다.
3. 기존 Rust 재사용 후보를 확인한다. 함수 존재 여부와 수치·상태 갱신 일치는 구분한다.
4. 입력, 출력, 변경 가능한 필드, 호출 시점, 사용하지 않는 분기를 확정한다.
5. C++ 원본의 최소 wrapper 또는 검증된 EP trace를 기준으로 단위시험을 만든다.
   테스트에 reference snapshot을 쓰는 것은 허용하되 생산 runtime에 oracle 값이나 fixture를 공급하지 않는다.
6. 그 카드 범위만 구현/수정한다. 하위·상위 알고리즘을 임의의 근사식으로 대체하거나
   tolerance를 완화하거나 실패시험을 삭제해서 통과시키지 않는다.
7. 정상·경계·0·비제로 활성·상태전이·실패 시험을 실행한다.
8. 필요한 선행/후행 연결시험과 기존 회귀시험을 실행한다.
9. 실제 실행 명령, 소스/입력해시, 결과 파일, 남은 차이, 실행하지 못한 검증을 기록한다.
10. 네 개 gate와 해당 scope의 선행 gate가 충족된 경우만 완료 체크한다.
    구현만 존재하거나 guard가 항상 false였던 경우 완료로 표시하지 않는다.

커밋/브랜치 변경이나 저장소 반영은 별도의 사용자 지시 범위에 따른다.
