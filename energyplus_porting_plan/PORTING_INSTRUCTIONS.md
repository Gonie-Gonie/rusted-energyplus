# EnergyPlus 포팅 작업 지시

`Gonie-Gonie/rusted-energyplus`에서 아래 자료를 기준으로 실제 구현과 검증을 진행한다.
`energyplus_porting_task_cards.zip`을 저장소 루트에 풀어 `energyplus_porting_plan/`을 둔다.

1. `energyplus_porting_plan/README.md`, `STATE_CONTRACTS.md`, `CHECKLIST.md`, `plan.json`을 읽는다. EP 기준은 **26.1.0 / `6f2e40d10250a105b49966baa24d843711e61048`**로 고정한다.
2. 지정된 카드가 없으면 `CON-01`부터 시작하고, 이후 선행 조건을 충족한 미완료 카드를 하나씩 처리한다. 입력 범위를 임의로 확장하지 않는다.
3. 해당 `cards/<ID>.md`의 EP 함수·분기, 직접 보조 함수, 읽고 쓰는 상태와 호출 시점을 원본에서 확인한다. 카드에 오류·누락이 있으면 먼저 보완하고, 불필요하게 EP 전체를 다시 탐색하지 않는다.
4. 기존 Rust 구현을 우선 재사용·수정한다. EP의 계산식·분기·초기화·이력 갱신 순서를 보존하며, 근사식이나 시험값 주입으로 불일치를 감추지 않는다.
5. 동일 입력·초기 상태의 EP 기준 계산과 단위 비교 후 실제 실행 연결을 검증한다. 정상·경계·비제로 활성·여러 timestep을 시험하고, 허용오차를 통과 목적으로 완화하지 않는다.
6. **범위 확정, 단위 검증, 연결 검증, 생산 실행 연결**을 모두 확인한 카드만 완료 처리한다. 파일 존재나 빌드 성공만으로 체크하지 않으며, 실행하지 못한 시험은 미확인으로 남긴다.
7. 원본 코드 범위, 변경 파일, 시험 명령·결과, 남은 문제를 해당 카드에 기록하고 `CHECKLIST.md`와 `plan.json`을 갱신한다. 작업 종료 시 완료 카드·미완료 사유·다음 카드를 간단히 보고한다.

EP 출력·중간 상태는 시험 기준으로만 사용한다. 생산 실행은 지원 범위의 계산을 Rust 자체로 수행해야 한다. 계산 블록의 검증 뒤에는 `SYS-*`의 호출 순서·warmup·상태 인계·통합시험까지 완료한다.
