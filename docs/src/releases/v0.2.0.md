# eplus-rs 0.2.0

Limited-conformance Windows prerelease, 2026-11-20.

This release packages the verified bounded Source scope and makes its boundary
explicit. It does not claim complete EnergyPlus compatibility or every valid
combination of the listed objects.

- Explicit Source A/B guide and complete example-object inventory.
- Portable CLI, legacy Windows launcher, locked converter/reference runtime,
  a known Source A example and its weather file.
- Manifest, SHA256 checksums and third-party license notices.
- Shorter current documentation and an extracted-package verification gate.

Fixed CON-01 evidence retains 15 cases/16,427,880 values. The separate domain
archive retains 284 paired cases/13,276,216 values through Source212. Both use
declared tolerances; their totals are not combined. Packaging verification
does not add numerical conformance cases.

Source A covers bounded opaque unconditioned heat balance. Source B covers
bounded direct-Zone IdealLoads and documented extensions. Active windows,
general HVAC/Plant, sizing, EMS, PythonPlugin and AirflowNetwork remain outside
ordinary Source support. Unfinished Window work is excluded from this release.

Use the CLI with `--porting-scope A` or `B`; the launcher uses the older generic
route. First use `--dry-run` and read the support report. Ad-hoc runs retain
`conformance_claim=false`. Source A/B automatic oracle comparison is not
connected; use the separate-run verification guide.

Extract the entire ZIP and read `QUICKSTART.md` and `SUPPORT.md`. Preserve the
directory layout. No Rust installation is needed for the packaged CLI.
