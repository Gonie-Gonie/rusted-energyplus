# v0.1.0 Release Notes

v0.1.0 is the public limited-conformance pre-1.0 release of `eplus-rs`. It
packages the Rust CLI, the no-console Windows launcher, the locked EnergyPlus
26.1.0 oracle, and the generated evidence reports needed to understand exactly
which conformance claims are currently supported.

This release is conformance-first but intentionally narrow. It does not claim
full EnergyPlus compatibility, broad ExampleFiles compatibility, broad HVAC
simulation, plant simulation, EMS/PythonPlugin support, AirflowNetwork support,
or arbitrary-IDF numerical conformance.

## Included

- `eplus-rs.exe` CLI for model inspection, typed compile preview, conformance
  evidence commands, diagnostic runs, and arbitrary IDF/epJSON support
  assessment.
- `eplus-rs-launch.exe`, a small EPLaunch-style Windows launcher for choosing
  IDF/epJSON input, EPW weather, output folder, and optional oracle comparison
  without typing CLI commands.
- Bundled EnergyPlus 26.1.0 oracle runtime in release packages unless the
  package is intentionally built with `-SkipOracle`.
- Arbitrary IDF/epJSON run artifacts:
  `support-assessment.json`, `support-report.md`, `diagnostics.json`,
  `eplusrs.err`, `run-summary.json`, runtime result summaries, oracle outputs,
  and compare reports.
- Release evidence assets generated from the conformance manifests, support
  coverage registry, output variable coverage, algorithm ledger, and release
  evidence manifest.

## Conformance Claims

The release evidence is limited to declared cases, declared output variables,
declared tolerances, and blocking gates. The promoted scope includes:

- no-mass heat-balance and surface-temperature conformance cases
- declared schedule and weather time-series conformance
- official `1ZoneUncontrolled` dynamic heat-balance conformance candidate
  outputs for the selected weather, zone-air, surface-temperature, and surface
  conduction variables
- internal convective gain conformance for the declared
  `Zone Total Internal Convective Heating Rate` series
- IdealLoads no-OA sensible, capacity-limit, flow-limit,
  flow-and-capacity-limit, `ConstantSensibleHeatRatio`,
  `ConstantSupplyHumidityRatio`, humidistat, ReportPurchasedAir energy,
  fuel-efficiency, outdoor-air design-flow, economizer, heat-recovery, and
  facility-meter candidate gates where the manifests explicitly declare
  conformance-level outputs

Every claim remains tied to generated evidence. Ad-hoc arbitrary runs and
diagnostic projections keep `conformance_claim=false` even when oracle baseline
or comparison artifacts are generated.

## Evidence Assets

The release gate generates the full evidence pack under
`.runtime/release-evidence/v0.1.0` for local inspection, including PDF, HTML,
JSON, and Markdown variants where the report generator supports them.

The GitHub Release page is intentionally narrower. It publishes the Windows zip
and the public evidence PDFs:

- numeric conformance evidence
- conformance index
- support coverage
- user coverage handbook

## Scope Boundary

v0.1.0 should be treated as a limited-conformance pre-1.0 release. Users should
expect precise diagnostics and explicit support boundaries, not broad
EnergyPlus replacement behavior.
